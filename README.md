# Medix Admin MVP

MVP en Next.js (App Router) + TypeScript + Tailwind + Supabase Auth con **Magic Link**.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS


## Correr el codigo

- Remove-Item -Recurse -Force node_modules, .next
- copiar y cambiar datos del .env
- npm install
- npm run build
- npm run dev
